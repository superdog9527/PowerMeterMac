# Power Meter for Mac：产品定义与边界

## 定位

面向嵌入式、穿戴和低功耗设备研发的 macOS 桌面测量工具。产品提供安全可控的直流供电、电流波形观察、区间统计和原始数据导出，功能与 Windows 上位机的主要工作流一致。

## 主要工作流

1. 应用启动后自动检测一台 POWER Meter；复位后先尝试关断，读取最小身份信息，再以成功应答确认输出和采集均关闭，最后读取校准参数。未发现设备时每 3 秒重新检测。手动断开后暂停自动连接，可点击“连接设备”恢复。
2. 用户输入电压并确认设置；有效范围为 0.600–5.000 V，步进 1 mV。输出开启或采集运行时仍可修改。
3. 用户可开启电源输出，或在输出关闭时直接测量噪声/零点。
4. 用户选择 10、20、50 或 100 kHz 开始采样。
5. 波形实时滚动；关闭“实时视图”只冻结画面，后台继续采样。
6. 应用显示当前、平均、最小、最大电流和按设定电压计算的瞬时功耗。
7. 用户可把保留的数据导出为 CSV，包含样本序号、推算时间、电流、电压和功耗。

## 安全状态机

- 连接采用两阶段关断：身份查询前做一次尽力关断；验证型号和固件后必须成功关断输出及采集，才允许读取校准并进入就绪状态。
- 开启输出前必须在本次连接中成功设置过电压；不会从偏好设置恢复上次输出状态。
- 采集中调整电压由应用自动建立样本边界：暂停硬件采样、排空旧数据、保持输出状态、设置电压并按新校准恢复采样；采集中仍不能开启或关闭输出。
- 所有控制命令在 USB 发送前和应答后同步写入持久化 JSONL 日志。日志失败时拒绝发送新命令；开启输出结果不确定时立即尝试底层紧急关断。
- 断开、退出和正常关闭 USB 句柄时都会尝试停止采集和关闭输出。
- 5.000 V 设备上限在 Swift 输入层、设备描述符和 C USB 命令层分别检查。
- 通信失败时不声称输出已关闭，而是显示“硬件状态未知”，要求用户检查设备供电。

## 与 Windows 版的对应关系

| Windows 功能 | macOS 实现 |
| --- | --- |
| 自动/手动连接 | 启动时自动连接单设备；支持手动断开、重连及等待 USB 接入 |
| 0.5–5 V 电压控制 | 支持 0.6–5 V |
| 电源输出开关 | 支持，带本次会话电压确认 |
| 采样开关 | 支持 |
| 时间档位 | 100 ms、1 s、10 s、60 s |
| 实时/静态视图 | 支持，冻结不停止后台采集 |
| 滚轮缩放 | X 轴刻度区缩放时间并保持鼠标下时间位置；Y 轴刻度区缩放电流上限；其他区域忽略滚动 |
| 当前/平均/最大/最小/电压/功耗 | 支持 |
| 数据保存 | 增加 CSV 导出 |

## 已验证设备与协议

- USB：VID `0x0811`、PID `0xf122`
- 设备：`HH_PM_L2`，序列号 `260204002`
- 硬件：`V1.0.0`
- 固件：`V1.0.3`
- USB 数据帧：每帧 1000 个三字节 ADC/量程样本；固件每个序号发送两帧
- 硬件采样固定为 100 kHz；10/20/50 kHz 按 Windows SDK 算法在主机侧降采样
- 电流换算使用设备提供的电压相关校准表和 Windows SDK 的自动量程过渡滤波

## 明确不做

- 不支持超过设备描述符上限或 5.000 V 的输出。
- 不支持修改校准参数、固件升级、外部触发和自动电压扫描。
- 不支持多设备同时采集；发现多台设备时拒绝猜测目标设备。
- 不承诺设备端绝对时间戳或无损长时间记录。现有协议没有每样本时间戳，USB/系统调度异常会以帧异常计数呈现。
- 实时波形为可视化降采样；CSV 保存主机所选采样率下的数据。
- 横轴严格以样本序号 / 采样率计算，数据不足时留空；默认完整跨度 10 秒。横纵轴有数值刻度，纵轴上限手动选择，不逐帧自动调整。
- 时间缩放档位为 1 ms–60 s，电流上限档位为 1 nA–5 A。缩放只改变显示范围，不生成或修改采样数据。
- 绘图按时间顺序直线连接真实样本，不平滑、不插值；高密度视图只选取各组真实首尾及极值点，保留原始坐标。界面每秒刷新 10 次，USB 采样速率不受影响。
- “窗口平均”计算可见区间 [起点, 终点) 内全部真实样本，未采满部分不作为零参与计算；冻结视图使用快照计算。最小/最大仍针对整轮采集。
- 左栏支持设置 A/B：冻结视图后点击波形，按时间吸附至最近可见采样点，显示 X 秒、Y nA，以及 B−A 差值。A/B 保留为折线顶点，新采集及清除数据时重置。
- 保留最近 600 万个样本；历史视图使用冻结快照，后台继续采集。新一轮采集清空上一轮波形，导出使用该轮实际采样率。
- 当前发布包只验证了 Apple Silicon 和本机 macOS 环境，使用临时本地签名，未做 Apple 公证。
